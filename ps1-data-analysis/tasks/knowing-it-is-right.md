# Knowing it is right

Follow-up questions on Problem Set 1, drawn largely from `QUESTIONS.md`. Answer each one in one to
three sentences. None of them needs you to run code. One asks about a choice you made in task
3; the rest can be answered by anyone who did the assignment.

A practice draw takes 1 or more of these.

### q-missing-filter

On PS1, Task 1 keeps only movies with at least 50 ratings. If that filter were missing, what would the
top of the list look like, and how would you spot that from the output alone, without reading
any code?


### q-undatasettable

What kind of mistake can you imagine that you could not build a test dataset for?


### q-different-language

On PS1, why a different language for the second implementation, rather than a second Python version?


### q-similarity-definition

On PS1 task 3, what was your alternative definition of similarity between a pair of users? Say why it gives a more interesting result about the number of movies rated in common.
