# SI 212 — assignments

**This is where the work you hand in lives.** Each assignment arrives here as a folder with its
own instructions, and your answer goes in the same folder.

## This copy is a starting point, and then it is yours

You clone this repository during first-day setup. In week 2 you publish it as **your own private
repository** and add the teaching team to it, before the first thing is due in week 3.

It keeps a second remote called `upstream`, pointing back here. New assignments and corrections
to existing ones reach you with `git pull upstream main` — so an assignment you have already
started can be updated without anyone copying files around, and without losing what you wrote.

## Who can see it

**You and the teaching team.** That is the difference between this repository and
[learning-topics](https://github.com/umsi212F2026/learning-topics), which stays private to you.
Handing something in means committing it here and pushing.
